# recall_java
## 목표
1. 고전 자바 문법 복습하기
   * Generics, Enum, Annotation
   * 바로 써먹을 수 있는 자료구조
2. 자바를 이용한 여러가지 연습
   * Gradle, LomboK

**<연습방법>**
* chatGPT를 통해서 문제를 만들어서 연습한다.
* 한 문제 = 하나의 패키지라고 생각하고 만들기

## [패키지와 클래스](./src/main/java/part1)
**<목표>**
* 하나의 패키지 안에 여러개의 클래스를 쓰기
* 하나의 클래스 안에 여러개의 클래스를 쓰기
* 하나의 클래스 안에 여러개의 메소드를 쓰기
* private, public, protected 연습하기
* static 연습하기

## [여러 개의 클래스](./src/main/java/part2)
* 상속, 접근제어자
